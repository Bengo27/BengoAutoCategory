# Bengo AutoCategory – מדריך לסטרימרים

התוכנה מזהה איזה משחק פתוח אצלך ומשנה לבד את הקטגוריה בקיק. בלי לגעת בדשבורד באמצע שידור.

## התקנה (2 דקות)

1. מורידים את **BengoAutoCategory.exe** מהקישור שקיבלת.
2. שמים אותו בתיקייה קבועה, למשל `Documents\BengoAutoCategory`, ולא בתיקיית Downloads.
3. מריצים. אם Windows מציג מסך כחול ("Windows protected your PC") → **More info** → **Run anyway**.
   זה קורה כי התוכנה חדשה ועדיין לא חתומה דיגיטלית.

## חיבור לקיק (דקה)

1. בתוכנה: **חיבור לקיק** → **התחבר לקיק**.
2. נפתח דף של קיק בדפדפן → מתחברים לחשבון (אם צריך) → **מאשרים**.
3. חוזרים לתוכנה, ואמור להופיע "מחובר לקיק בתור …". זהו.

> הסיסמה של קיק לא עוברת דרך התוכנה. ההתחברות נעשית בדף של קיק עצמו.
> ההרשאות: קריאת פרטי המשתמש, וקריאה ועדכון של פרטי הערוץ (כותרת/קטגוריה). בלי צ'אט ובלי מפתח שידור.

## שימוש

- פשוט משחקים. אחרי 20 שניות במשחק, הקטגוריה בקיק מתחלפת.
- Alt-Tab לדיסקורד / OBS / דפדפן לא משנה כלום.
- סוגרים את המשחק → אחרי כמה דקות חוזרים ל-Just Chatting (אפשר לשנות בהגדרות).
- משחק חדש מ-Steam/Epic מזוהה לבד. משחק שלא קיים בקיק עובר ל-**Games + Demos**.
- משחק שלא זוהה? בלוח הבקרה לוחצים **הוסף כלל**.
- סגירת החלון ממזערת את התוכנה לאייקון ליד השעון, והיא ממשיכה לעבוד.

## עדכונים

כשיש גרסה חדשה, מופיע בלוח הבקרה פס ירוק **"גרסה חדשה זמינה"** → **עדכן עכשיו**. התוכנה מתעדכנת ונפתחת מחדש.

## בעיות?

שלחו למי שנתן לכם את התוכנה צילום מסך של **יומן הפעילות**, או את קובץ היומן: הגדרות → פתח (תיקיית הנתונים) → `logs`.
