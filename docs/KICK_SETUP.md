# חיבור לקיק – מדריך הגדרה

ההגדרה נעשית פעם אחת ולוקחת כ-5 דקות.

## למה צריך "אפליקציית מפתחים"?

קיק מאפשר לתוכנות לשנות קטגוריה רק דרך ה-API הרשמי, ורק לתוכנה שרשומה כ"אפליקציה" בחשבון קיק. לכל אפליקציה יש **Client ID** (מזהה ציבורי) ו-**Client Secret** (סוד). לפי התיעוד הרשמי, קיק דורש את ה-Secret גם בהתחברות וגם ברענון החיבור, ולכן כרגע כל סטרימר יוצר אפליקציה משלו.

> בעתיד, כשהתוכנה תופץ לסטרימרים רבים, אפשר להעביר את ה-Secret לשרת קטן אחד, ואז אף סטרימר לא יצטרך לעבור את השלב הזה. הקוד בנוי כך שהמעבר יהיה פשוט.

## שלבים

### 1. אימות דו-שלבי (2FA)
בהגדרות חשבון הקיק → Security, ודא ש-2FA מופעל. בלי זה עמוד המפתחים לא נפתח.

### 2. יצירת אפליקציה
1. היכנס ל-https://kick.com/settings/developer (אפשר גם מהכפתור בעמוד "חיבור לקיק" בתוכנה).
2. צור אפליקציה חדשה:
   - **שם:** למשל `Catego`
   - **Redirect URL:** בדיוק `http://localhost:47653/callback` (אפשר להעתיק מהתוכנה בלחיצה)
   - **הרשאות (Scopes), אם מופיעה בחירה:** `user:read`, `channel:read`, `channel:write`
   - **Webhook:** לא צריך
3. שמור והעתק את ה-**Client ID** ואת ה-**Client Secret**.

### 3. הזנה בתוכנה
1. בתוכנה: **חיבור לקיק** → שלב 2 → הדבק Client ID ו-Client Secret → **שמור פרטים**.
2. לחץ **התחבר לקיק**. ייפתח דף של קיק בדפדפן – אשר את ההרשאות.
3. יופיע דף "התחברת לקיק בהצלחה", והתוכנה תציג **מחובר לקיק בתור …**.

### 4. בדיקה
1. בעמוד "חיבור לקיק" לחץ **בדוק את הכללים מול קיק** – התוכנה תוודא שכל קטגוריה בכללים קיימת בקיק.
   - קטגוריה שלא נמצאה: **כללי קטגוריות** → ערוך → **חפש בקיק** → בחר את התוצאה הנכונה.
2. מומלץ לבדיקה ראשונה: כבה **שינוי קטגוריה אמיתי בקיק**, שחק 20 שניות, וודא ביומן שהזיהוי נכון. אחר כך הדלק אותו.
3. עם שינוי אמיתי מופעל: פתח משחק → אחרי 20 שניות הקטגוריה בערוץ תשתנה. אפשר לבדוק ב-kick.com.

## אבטחה

- **הסיסמה של קיק לא עוברת דרך התוכנה** – ההתחברות נעשית בדף הרשמי של קיק.
- ה-Client Secret והטוקנים נשמרים מוצפנים (Windows DPAPI) בקובץ `%AppData%\BengoAutoCategory\kick_auth.json`. רק המשתמש שלך במחשב הזה יכול לפענח אותם.
- ההרשאות שהתוכנה מבקשת: קריאת המשתמש, קריאת הערוץ ועדכון הערוץ (כותרת/קטגוריה). בלי צ'אט, בלי מפתח שידור.
- **התנתק** מבטל את ההרשאה גם בשרת של קיק.
- אסור לשתף את ה-Client Secret. אם הוא דלף – צור אותו מחדש בעמוד המפתחים, ועדכן בתוכנה.

## פתרון בעיות

| בעיה | פתרון |
|---|---|
| קיק מציג שגיאה על redirect_uri | ה-Redirect URL באפליקציה חייב להיות **בדיוק** `http://localhost:47653/callback` |
| "לא ניתן לפתוח את הפורט המקומי 47653" | תוכנה אחרת משתמשת בפורט. סגור אותה (או הפעל מחדש את המחשב) ונסה שוב |
| "קיק דחה את בקשת ההתחברות (401)" | ה-Client ID או ה-Secret שגויים – העתק אותם שוב |
| "לקיק אין הרשאה לפעולה הזו (403)" | חסרה הרשאת `channel:write` – התנתק, הוסף את ההרשאה באפליקציה, והתחבר מחדש |
| "הקטגוריה X לא נמצאה בקיק" | ערוך את הכלל ובחר את הקטגוריה דרך "חפש בקיק" |
| "החיבור לקיק פג" | לחץ "התחבר לקיק" שוב |
